# 🤖 ChatBot Terminal com Clima

Um simples ChatBot de terminal feito com Node.js que responde saudações e fornece **previsão do tempo** utilizando a API da [OpenWeatherMap](https://openweathermap.org/api).

---

## 🚀 Como executar

```bash
# Clone o repositório
git clone https://github.com/SEU_USUARIO/chatbot-terminal-clima.git
cd chatbot-terminal-clima

# Instale as dependências
npm install

# Crie o arquivo .env com sua chave da API
echo "OPENWEATHER_API_KEY=SUA_CHAVE" > .env

# Execute o bot
node chatbot.js
